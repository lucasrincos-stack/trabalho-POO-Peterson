03 · Encapsulamento

Propriedades validam os dados.

@property
def salario(self):
    return self.__salario

@salario.setter
def salario(self, valor):
    if valor <= 0:
        raise ValueError("Salário deve ser positivo")
    self.__salario = float(valor)

Nome, idade e salário têm validações para evitar valores inválidos.

04 · Herança

As subclasses reutilizam a inicialização.

class Gerente(Funcionario):
    def __init__(self, nome, idade, salario, tamanho_equipe):
        super().__init__(nome, idade, salario)
        self.tamanho_equipe = tamanho_equipe

Desenvolvedor e Estagiario também herdam de Funcionario.
